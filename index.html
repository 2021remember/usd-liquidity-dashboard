一、五项核心条件（全部满足才出现“美元荒警报开启”）

  • ① 10Y 收益率快速上行：当前值较前收盘 ≥ +10bp
  • ② DXY 暴力拉升：当前值较前收盘 ≥ +1.50%
  • ③ 纳指100 放量跌破支撑：日跌幅 ≥ 2.50% ＋ 现价低于20日支撑 ＋ 量比 ≥ 1.2×（系统自动计算）
  • ④ 现货黄金持续破位：2日累计跌幅 ≥ 2.0% ＋ 现价低于20日支撑（系统自动计算）
  • ⑤ 融资/流动性指标恶化（任一）：SOFR 较上次 ≥ +15bp，或 TGA 较上次 ≥ +$50B，或 ON RRP 较上次 ≤ -$50B
  • 辅助观察：标普500日跌幅 ≥ 3.00%；高收益债利差 ≥ 600bp；GLD 单日净流出 ≥ 3.0 吨

二、顶部总判定逻辑

  • 5 / 5 满足：深红色“美元荒警报开启”。
  • 2–4 项同时触发：红色“流动性警报”；此时尚未满足全部五项，不等同于正式开启美元荒警报。
  • 仅 1 项触发：黄色“流动性关注”。
  • 0 项触发且 5 项均可判定：绿色“当前无美元荒风险”。
  • 数据尚未同步完成：灰色“数据同步中，暂不判断”，不会为了显示绿色而忽略缺失数据。
  • 辅助指标单独警报：黄色“局部指标关注”，不会计入 5 项核心条件，但会提醒你查看细节。

三、行状态与阈值

每一行会自动显示“正常 / 关注 / 警报 / 待同步”。达到接近阈值标为关注，达到警报阈值标为警报；核心行达到警报阈值即代表对应核心条件满足。

  • DXY：关注 ≥ +0.80%，警报 ≥ +1.50%
  • 10Y：关注 ≥ +5bp，警报 ≥ +10bp
  • 纳指100：跌幅接近 1.50% / 跌破20日支撑时关注；跌幅 ≥ 2.50% 且跌破支撑且量比 ≥ 1.2× 时警报
  • 黄金：日跌幅或2日跌幅接近 1.0% / 跌破20日支撑时关注；2日跌幅 ≥ 2.0% 且跌破支撑时警报
  • SOFR：关注 ≥ +5bp，警报 ≥ +15bp
  • TGA：关注 ≥ +$20B，警报 ≥ +$50B
  • ON RRP：关注 ≤ -$20B，警报 ≤ -$50B
  • 高收益债利差：关注 ≥ 450bp，辅助警报 ≥ 600bp
  • GLD 持仓：净流出 ≥ 1.0 吨关注；净流出 ≥ 3.0 吨辅助警报
  • 标普500：日跌幅 ≥ 1.50% 关注；≥ 3.00% 辅助警报

四、全自动实时抓取说明

页面启动后会自动抓取全部 10 项，无需任何手工录入：DXY、10Y、纳指100、标普500（Yahoo Finance）；现货黄金（GoldAPI 实时价，参考前收、20日支撑和2日跌幅用 COMEX 黄金历史数据计算）；SOFR 与 ON RRP（纽约联储市场 API）；TGA（美国财政部 Fiscal Data）；高收益债利差（FRED）；GLD 每日持仓（SPDR Gold Shares 官方 XLSX 历史档案自动解析）。

行情类数据是准实时报价，其中现货黄金每20秒单独刷新一次；官方日度数据通常每个交易日更新一次，GLD 持仓在盘后更新。不同平台对现货黄金的买卖价、数据源和延迟不同，出现几美元差异属于正常现象，页面会显示 GoldAPI 的数据时间。为避免无意义地反复请求，SOFR / TGA / ON RRP / 高收益债利差缓存15分钟，GLD 官方档案缓存1小时。每行会标出来源和数据日期；抓取失败时不会清空原有数值，下一次自动刷新或点击“立即刷新”会继续重试。

浏览器直连 Yahoo / FRED 会被 CORS 拦截，因此默认通过可配置的公共 CORS 代理读取；代理只转发公开行情请求。纽约联储、美国财政部、GoldAPI、SPDR 官方接口支持浏览器直连。数据源组合参考了 GitHub 上同类开源实现（如 LiquiLensLabs/seiche、jqz576-lab/Market-Radar）的思路，本页优先使用官方免密钥源。

五、数据口径

10Y、SOFR 按百分比处理；TGA、ON RRP 按“十亿美元”处理；高收益债利差按 bp；GLD 持仓按吨。20日支撑取最近20个交易日的盘中最低价；量比 = 当前交易日成交量 / 前20个交易日均量；黄金2日跌幅取 COMEX 黄金主连最近两日变化，现货价格来自 GoldAPI。全部指标由系统计算，不需要填写任何关键位或勾选项。

本页面只做规则化记录与提醒，不构成任何投资建议。自动数据可能延迟、修订或抓取失败，重大判断请以官方原始数据为准。

数据与笔记只保存在本机浏览器；页面仅向公开数据源发起只读请求，不上传你的数据。
