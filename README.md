# 美元流动性监控台

一个纯前端的美元流动性危机监控面板，单文件 `index.html`，不需要后端、不需要数据库，手机和电脑浏览器都能直接打开使用。

用来观察是否出现类似 2008、2020 年那种「美元荒」踩踏信号。

## 功能

### 1. 十项指标全部自动抓取

不需要手动录入任何行情数字。

**价格行情类**

- 美元指数 DXY
- 美国 10 年期国债收益率（收益率上涨 = 美债价格下跌）
- 现货黄金 XAU/USD
- 纳斯达克 100 指数
- 标普 500 指数

**流动性预警类**

- SOFR 担保隔夜融资利率
- TGA 美国财政部现金账户
- ON RRP 隔夜逆回购余额
- 美国高收益债利差
- GLD 黄金 ETF 每日持仓

### 2. 每行都告诉你「线在哪、差多少」

每张指标卡会显示：

- 当前数值、对比基准值
- 关注线、警报线的**绝对位置**（例如 DXY 关注线 = 前收盘 × 1.008）
- 当前值距离该线**还差多少**，或**已经越过多少**
- 数据来源与数据时间

### 3. 固定的警报规则

五项核心条件全部满足，才判定「美元荒警报开启」：

| 序号 | 条件 | 判定阈值 |
| --- | --- | --- |
| ① | 10 年期美债收益率快速上行 | 较前收盘 ≥ +10bp |
| ② | 美元指数暴力拉升 | 较前收盘 ≥ +1.50% |
| ③ | 纳指 100 放量跌破关键支撑 | 日跌幅 ≥ 2.50% 且跌破 20 日支撑且量比 ≥ 1.2× |
| ④ | 现货黄金持续破位 | 2 日累计跌幅 ≥ 2.0% 且跌破 20 日支撑 |
| ⑤ | 融资/流动性恶化（任一） | SOFR ≥ +15bp 或 TGA ≥ +$50B 或 ON RRP ≤ -$50B |

辅助观察指标：标普 500 日跌 ≥ 3.00%、高收益债利差 ≥ 600bp、GLD 单日净流出 ≥ 3.0 吨。

顶部总判定逻辑：

- 5 / 5：深红「美元荒警报开启」
- 2–4 项：红色「流动性警报」
- 仅 1 项：黄色「流动性关注」
- 0 项且五项均可判定：绿色「当前无美元荒风险」
- 数据未同步完成：灰色「数据同步中，暂不判断」

### 4. 阈值可以在页面里直接改

页面里的「阈值设置」面板有 22 个可调数值：

- 改完失焦或回车立即生效，**不需要重新部署网页**
- 速查表、距离提示、核心条件说明、顶部判定、K 线里的阈值线同步刷新
- 保存在浏览器本地，刷新不丢
- 一键恢复默认

### 5. 每个指标都能看 K 线 / 走势

- 行情类指标支持 1 分钟 / 5 分钟 / 15 分钟 / 30 分钟 / 1 小时 / 3 小时 / 4 小时 / 日线
- 可拖动平移、滚轮或双指缩放、双击复位
- 图内标出关注线、警报线、20 日支撑
- SOFR、TGA、ON RRP、高收益债利差、GLD 持仓是官方日度数据，只能显示日线走势

### 6. 本地保存

- 笔记、阈值设置保存在浏览器 localStorage
- 支持导出 / 导入备份，方便换设备迁移

## 数据来源

| 数据 | 来源 | 更新频率 |
| --- | --- | --- |
| DXY、10Y、纳指 100、标普 500 | Yahoo Finance | 准实时（经 CORS 代理） |
| 现货黄金 | GoldAPI | 每 20 秒轻量刷新 |
| SOFR、ON RRP | 纽约联储市场 API | 每交易日 |
| TGA | 美国财政部 Fiscal Data | 每交易日 |
| 高收益债利差 | FRED（BAMLH0A0HYM2） | 每交易日 |
| GLD 每日持仓 | SPDR Gold Shares 官方 XLSX | 盘后 |

浏览器直接请求 Yahoo / FRED 会被 CORS 拦截，默认通过可配置的公共代理读取，可在页面「数据源」里更换。

---

## 使用注意

- 页面关闭后，iPhone 不允许网页在后台持续刷新；下次打开会自动拉取最新数据。
- 不同平台现货黄金的买卖价和数据延迟不同，出现几美元差异属正常现象。
- 官方日度数据（SOFR、TGA、ON RRP、利差、GLD）每个交易日只更新一次。
- 本页面只做规则化记录与提醒，**不构成任何投资建议**。

## 本地使用与更新（Windows）

这台电脑已经配置好，**不需要登录 GitHub 网页**也能拉取和推送。

便携版 Git 位置：`D:\Tools\PortableGit\cmd\git.exe`（免安装、不需要管理员权限）

```powershell
$env:PATH = "D:\Tools\PortableGit\cmd;" + $env:PATH
cd D:\美元流动性监控台\github-repo
git pull            # 拉取最新
git status          # 查看改动
```

更新线上页面的两种方式：

1. 本仓库提交后推送：`git add -A; git commit -m "update"; git push`，GitHub Pages 会自动重新构建（约 30–90 秒）。
2. 直接在项目根目录双击 `发布工具\github_publish.bat`，走 GitHub API 覆盖 `index.html`，不需要 git。

主入口 Cloudflare 的更新：双击 `更新入口\一键发布到Cloudflare.bat`。

> 提交凭据保存在本机 `%USERPROFILE%\.git-credentials`，撤销 token 后需要重新写入。
